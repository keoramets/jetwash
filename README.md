# JetWash (Pvt) Ltd website

The public website of JetWash (Pvt) Ltd, an industrial cleaning and maintenance company founded in 1998. Built and
maintained by Julius (keoramets).

It's **frontend only**: Next.js builds every page as a static file (`output: 'export'` in `next.config.mjs`), and
Netlify serves them. There's no server, database, sign-in or client portal. The contact and quote request forms go
to **Netlify Forms**, which stores each submission and emails it to JetWash.

The earlier full-stack version (client and admin portals, PostgreSQL, Railway) is kept on the branch
`archive/fullstack-portal`.

## Pages

Home, About, Services (one page per service), Projects, Who we work with, Contact (with a Google map), Request a
Quote, Privacy and Terms. Plus `sitemap.xml`, `robots.txt` and the web manifest, all written at build time.

## Folders

```text
app/(public)/      the pages
app/sitemap.js     sitemap (services and projects from lib/)
app/robots.js      crawler rules
components/forms/  ContactForm and QuoteRequestForm (Netlify Forms)
components/public/ navigation, footer, WhatsApp/contact button, the project page (see lib/projects.js)
components/seo/    Google Analytics (only when its ID is set) and JSON-LD
lib/company.js     company facts and the six services: only what JetWash has confirmed
lib/projects.js    project stories: empty until JetWash sends real, approved jobs
lib/photos.js      the photos on the pages, with who took them and where they came from
lib/seo.js         contact details, map pin, page metadata
public/images/     logo files (generated by brand/gen.py), photos, share image
netlify.toml       build settings, security headers, redirects from the old portal addresses
```

## Work on it

Node.js 20.19 or newer (`.nvmrc` says 22).

```bash
npm install
npm run dev      # http://localhost:3000
npm run lint
npm run check    # structure check: JavaScript only, and no server or database files
npm run build    # writes the static site to out/
```

To look at the built site, serve `out/` with any static server, for example `npx serve out`.

The forms only work on Netlify: locally nothing is sent, whatever the page says. To try them, use a Netlify
deploy preview (every pull request gets one).

## Settings

All optional, read at build time (`.env` locally; on Netlify under Site configuration → Environment variables).
None is secret. See `.env.example`.

- `NEXT_PUBLIC_SITE_URL`: the site's address for canonical links and the sitemap. Netlify sets `URL` itself, so
  this is only needed to override it.
- `COMPANY_NAME`, `COMPANY_EMAIL`, `COMPANY_PHONE`, `COMPANY_ADDRESS`, `NEXT_PUBLIC_COMPANY_WHATSAPP`: JetWash's
  details. Without them, the site uses the same details from `lib/seo.js`.
- `NEXT_PUBLIC_GOOGLE_ANALYTICS_ID`: switches Google Analytics on (the privacy page then mentions it).
- `NEXT_PUBLIC_GOOGLE_SITE_VERIFICATION`: Google Search Console's verification token.

## Netlify

- **Build:** `netlify.toml` runs `npm run build` and publishes `out/`. Netlify builds every push to `main` and makes
  a deploy preview for every pull request.
- **Forms:** Netlify finds the `contact` and `quote-request` forms in the built pages. To choose who gets each
  submission by email, go to Site configuration → Forms → Form notifications (for example info@jetwash.co.zw).
  Submissions also stay in the Forms tab. Netlify's free plan includes 100 submissions and 10 MB of uploaded files
  a month; the quote form accepts files up to 8 MB.
- **Domain:** add jetwash.co.zw under Domain management and follow Netlify's DNS steps at the domain's registrar.

## Photos

The photos in `public/images/photos/` are free stock photos from Unsplash (listed in `lib/photos.js`). They show the
kind of work JetWash does, not JetWash's own jobs, staff or equipment: never caption them as JetWash work and never
use them for projects. To use JetWash's own photos, replace a file with one of the same name (landscape, about 1600
pixels wide, JPG) and update its `alt`, `by` and `source` in `lib/photos.js`.

## Projects

`lib/projects.js` is empty, so `/projects` says the stories are on their way. To add the first project, follow the
comment in that file and in `components/public/ProjectDetailPage.js` (a static site can't have a project page route
with no projects, so the route is added with the first one; `npm run check` reminds you).

## Branding

Colours are CSS variables at the top of `app/globals.css`. Logo files are generated by `brand/gen.py`: never edit
them by hand.
