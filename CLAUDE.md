# JetWash website: guide for Claude Code

Client project for JetWash (Pvt) Ltd, a Zimbabwean industrial cleaning and maintenance company established in 1998.
Built and maintained by Julius (keoramets). Next.js 16 App Router, React 19, plain JavaScript (JSX). Frontend only
(Julius, 12 Nov 2026): a static export (`output: 'export'`) hosted on Netlify, with no server, database, sign-in or
portal. The contact and quote forms are Netlify Forms. The old full-stack version is on `archive/fullstack-portal`.
See README.md.

## Commands
- `npm run dev`: http://localhost:3000 (`.env` is optional, see `.env.example`)
- `npm run lint`, `npm run check` (structure: JavaScript only, no server or database files), `npm run build` (to out/)

## Rules
- Company facts and services live in `lib/company.js`. Only put in what JetWash has confirmed. Never invent clients,
  testimonials, project results, figures or leadership quotes; leave a section out until the real content exists.
- Contact details come from the build environment (`COMPANY_*`, `NEXT_PUBLIC_COMPANY_WHATSAPP`). If one is missing,
  the site falls back to JetWash's real details in `lib/seo.js`. Keep those and `.env.example` in step.
- Frontend only: no API routes, middleware/proxy, database or server code. Every page must build as static HTML.
  Services come from `lib/company.js`, projects from `lib/projects.js` (empty until JetWash sends real, approved jobs).
- Forms are Netlify Forms (`components/forms`): keep `name`, `data-netlify`, the hidden `form-name` and the
  `bot-field` honeypot. A new field goes in the form's JSX (Netlify reads the built HTML).
- Keep the JetWash brand (navy, emerald, pale blue). This is not a Global Alfabet product.
- The logo files in `public/images/brand/` are generated by `brand/gen.py` (see `brand/README.md`): never edit them
  by hand. Use the files, never redraw the logo in a component.
- Photos are listed in `lib/photos.js` with who took them and where they came from. Use JetWash's own approved photos
  or free-licensed stock photos (Unsplash, Pexels, or Wikimedia Commons with the credit its licence asks for). Never
  copy a photo from another website. Stock
  photos only illustrate the kind of work: never caption them as JetWash jobs, staff or results, never use them for
  projects, and blur out other companies' logos and phone numbers.
- Plain JavaScript only (`npm run check` rejects TypeScript files).
- Security: keep `next` and `react` patched; CI fails on high or critical advisories in runtime dependencies.
  Security headers and redirects are in `netlify.toml`. Never commit `.env` files or secrets.
- Work on a branch and open a pull request. Julius approves every merge.
- Commit messages: conventional style, e.g. `feat(services): add tank inspection`, `fix(contact): map height`.
